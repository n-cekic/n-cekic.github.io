# Nikola Cekić — Resume site

Static, responsive resume site intended for GitHub Pages.

## Files

- `index.html` — content and small theme/print scripts
- `styles.css` — responsive layout, dark mode, and print styles
- `favicon.svg` — simple favicon
- `.nojekyll` — tells GitHub Pages to serve the site as plain static files

## GitHub Pages

This repository is intended to publish as the user site at:

`https://n-cekic.github.io/`
