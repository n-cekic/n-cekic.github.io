Backend Software Engineer (Junior → Mid)

Finbet · Belgrade, Serbia · Hybrid

Jul 2023 — Present

Worked primarily on the Bonus Engine product in a Go-based betting platform comprising roughly 80 microservices, with about 10 under active development in the relevant product area.

  • Built the standalone Go Bonus Cost service as part of a redesign of campaign-cost tracking, including Kafka ingestion, concurrent aggregation by bonus ID, PostgreSQL persistence, Flyway migrations, and tests with approximately 70% coverage. The redesign exposed before/after bonus state in Kafka events, eliminating typically 1–3 database reads per settlement, reducing repeated writes through batching, and removing lag-induced overspend scenarios observed during testing.
  • Diagnosed and fixed a production memory leak using Grafana and pprof allocation profiles, tracing it to incorrect Gorilla context usage and eliminating recurring OOM failures.
  • Automated Flyway migration validation in GitLab CI, blocking duplicate, incorrectly ordered, or malformed migrations before merge and eliminating recurring version conflicts; DevOps later incorporated the validator into shared quality jobs alongside tests and linting.
  • Standardized local development with Docker Compose and VS Code debug configurations, reducing technical onboarding from roughly two weeks to under a week; also helped onboard and mentor three junior engineers.
More contributions
  • Worked with the team lead to establish structured peer code reviews as a pre-merge expectation, regularly reviewing teammates’ changes and improving practices around database error handling, GoDoc, documentation, and general code quality.
  • Initiated and delivered three cross-team technical sessions for approximately 15 engineers on Go concurrency patterns, error handling, and database mocking, using prepared slides and code examples.
  • Evaluated Keploy through a proof of concept, authored an Architecture Decision Record documenting benefits, costs, and dependency risks, and presented the trade-offs to the team; the tool was ultimately not adopted.
